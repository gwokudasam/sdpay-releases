# SDPay for Android: releases

Signed builds of the SDPay wallet app. The app checks this page for updates.

**Install:** open [the latest release](../../releases/latest) on the phone, download the `.apk` and open it.
Android asks once to allow installs from the browser.

**Update:** the app offers a newer release on its home screen and under Settings → Check for updates.

Builds are produced by the workflow in this repository from the app's private source.
